موقع فريق مصادر التعلم المدرسية
================================

محتويات المجلد
- index.html  : الصفحة الرئيسية (السلايدر + الأخبار + من نحن)
- team.html   : صفحة الفريق (الهيكل الهرمي)
- member.html : الصفحة الشخصية للعضو + بطاقة QR
- admin.html  : لوحة التحكم (لقائد الفريق)
- data.js     : ملف البيانات المركزي (أعضاء، أخبار، إعدادات)
- assets/     : الشعاران (school-logo.jpg و team-logo.png) — استبدلهما بنفس الاسم لتغيير الشعار
- css/ و js/  : التصميم والبرمجة

أهم ملاحظتين
1) كلمة مرور لوحة التحكم الافتراضية 1234 — غيّرها من: لوحة التحكم > إعدادات الموقع.
2) بعد النشر، ضع رابط الموقع النهائي في: إعدادات الموقع > رابط الموقع النهائي، حتى يعمل رمز QR صحيحاً.

الرفع على GitHub Pages
1. أنشئ حساباً على github.com ثم New repository، سمّه مثلاً: resources-team، واجعله Public.
2. اضغط "uploading an existing file" وارفع كل محتويات هذا المجلد (الملفات والمجلدات نفسها، وليس المجلد الأب).
3. اضغط Commit changes.
4. من Settings > Pages: اختر Branch: main و Folder: /(root) ثم Save.
5. بعد 1-2 دقيقة يظهر الرابط: https://اسم-حسابك.github.io/resources-team/

الرفع على Vercel
1. ادخل vercel.com وسجّل بحساب GitHub.
2. Add New > Project > اختر المستودع > Deploy (بدون أي إعدادات).
3. تحصل على رابط ينتهي بـ vercel.app.

تحديث المحتوى لاحقاً
1. افتح admin.html وعدّل (أعضاء، أخبار، صور).
2. من تبويب "النشر" اضغط "تصدير data.js".
3. في GitHub: افتح data.js > أيقونة القلم > الصق المحتوى الجديد > Commit.
